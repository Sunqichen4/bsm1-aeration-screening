# M3科学图与数据

本目录的图由`../make_figures.py`读取已保存的表格生成；未插入模拟之外的数据、置信区间或拟合平滑。图内英文，浓度为mg N/L。

## 图1：参数诊断与开发集

`M3_identifiability_and_development`，提供PNG、600 dpi TIFF、SVG和PDF。

可用图注：M3参数诊断与开发集连续目标表现。a，归一化参数坐标下稳态氨氮输出的局部敏感度Jacobian奇异谱，各谱除以自身最大奇异值；差分步长1e-5，虚线表示相对秩阈值1e-6。b，参数在预设搜索区间中的位置；固定ρ的两个5参数模型也显示其固定ρ位置。c，每个固定ρ重新拟合其余5参数后的开发稳态RMSE，星号为自由ρ模型；线段仅连接已计算剖面网格，不表示置信区间。d，同一750案例上的有限积分氨氮峰值RMSE；历史M2使用二元监督，其余使用连续目标，故历史模型为背景比较。

`development_plot_data.csv`保留d面板使用的全部模型数值；a–c的源记录分别见`../outputs/development/identifiability.json`、`models.json`和`rho_profile.csv`。局部满秩与边界拟合不能证明物理参数可辨识。

## 图2：冻结后新工况验证

`M3_new_condition_validation`在全部原生参考及审计完成后生成，提供相同四种格式。

可用图注：六个新恒定工况的冻结后独立评价。a，42个预设粗网格候选的NH4峰值RMSE。b，全部90候选在核验前的错误放行和保守误拒数量；标注依次为两类数量。c，自由ρ完整模型、RBF回归及历史M2在全部候选上的预测与原生参考峰值，虚线为一致线。d，经验浓度缓冲Gate请求的参考数量与最终错误；独立科学审计另为全部候选计算参考。历史M2的核验也使用新浓度缓冲，不代表其旧KLa Gate。90点包括由五个新模型预测选择的48个加密点，不能解释为自然工况分布或90个相互独立的工况。

`validation_plot_data.csv`保存各层各模型的指标；c面板原始点见`../evaluation_joined.csv`。完整逐工况结果见`../metrics_by_condition.csv`。不从图中推断实厂有效性、低温/动态泛化或运行能耗收益。
