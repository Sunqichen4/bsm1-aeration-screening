# M3B科研图与图注

两图数据均来自120个已冻结候选及其独立审计通过的原生BSM1参考。图内浓度单位mg N/L，有效传氧z=αKLa单位d⁻¹。无随机误差线：本轮为确定性设计条件的单次参考积分，未据候选数构造总体置信区间。

**图M3B-1：六个新恒定工况的NH₄-N阈值邻域响应。** 各面板对应一个(L,α)组合，六条线连接该模型在冻结候选上的实际预测峰值，仅作视觉引导，不代表额外积分或拟合插值。黑色实心圆为108个预设固定网格参考，紫色空心菱形为12个由历史M2稳态预测交叉引导的加密参考。灰虚线为4 mg N/L限值，等于限值归为合规。主轴显示136≤z≤196 d⁻¹、0–12 mg N/L；各面板右上小图保留112与220守卫点及全部浓度范围。面板中的合规/超限数量按该工况全部20点计数。六个固定网格均观察到阈值两侧；这不证明响应全域单调、交叉唯一或首合规采样值为连续最优值。

文件：`M3B_threshold_response.png/.tiff/.svg/.pdf`。数据：`boundary_response_plot_data.csv`，同一参考会随6模型逐行重复，统计参考点数量时需按candidate_id去重。

**图M3B-2：固定108点的浓度误差、阈值决策及参考核验代价。** (a)六模型峰值RMSE；(b)原始误放及误拒数量，所有误放计数为0；(c)固定Gate要求核验的候选比例，柱顶为实际分子/108，柱内给出核验后错误数；(d)参考峰值距4不超过0.5 mg N/L的8个固定网格候选上的RMSE。每个面板均使用同一固定主格或其中相同的参考定义子集，未混入12个模型引导加密点。历史M2采用原二元监督，其余五模型使用连续峰值目标；过程模型另保留经验生物量闭合。自由ρ完整模型有6个可调参数，固定ρ完整及去反馈模型各有5个。Gate后标签对被核验点采用参考值，须与核验比例共同解释，零观察错误不构成总体风险保证。

文件：`M3B_fixed_grid_performance.png/.tiff/.svg/.pdf`。数据：`boundary_performance_plot_data.csv`、`boundary_near_threshold_plot_data.csv`。

图由`make_boundary_figures.py`生成，遵循drawing-skill：PNG 260 dpi、TIFF 600 dpi（LZW）、SVG与PDF保留可编辑文字。源数据与图文件哈希见`boundary_figures_manifest.json`。两张PNG均已实际打开检查，坐标、单位、图例及数值标注可见，无裁剪；全域小图保留所有采样范围。图M3B-2显示总体与近阈值排序不同，未隐藏该结果。
